# CollabPress

> ⚠️ VIBECODED: This entire project was generated by an AI coding agent. It is a toy/utopian system with NO security. Do not use in production.

Collaborative article publishing platform (toy/utopian, no security).

## Setup

Server:
```
cd server
npm install
npm start
```

Client:
```
cd client
npm install
npm run dev
```

Open http://localhost:5173. Server on http://localhost:4000.

## WordPress parity (via REA)
Studied WordPress's post editor, revisions, tags, and user roles; CollabPress mirrors posts/articles, revisions history, tags, and writer/editor roles, while adding real-time collaboration and chat escalation.

## Built vs mocked
- Real: username entry, request queue with upvotes, catalogue, editor with autosave, comments threading, chatroom escalation via WebSockets.
- Security: intentionally none. No passwords, no email, no hashing. Trust is the feature.
